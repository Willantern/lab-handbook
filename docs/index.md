## 使用前请注意

- 计算任务应通过 Slurm 提交，不要在登录节点执行长时间、高负载的训练。
- 共享软件和数据集默认只读，实验结果应保存到个人或项目目录。
- 示例中的分区、模块名、文件路径和资源数量是模板。请以用户当前配置为准。
- 本手册部署在公开的 GitHub Pages 上。不要在文档中提交密码、私钥、访问令牌或不适合公开的基础设施信息。
