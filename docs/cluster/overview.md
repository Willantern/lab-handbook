# 集群概览

本实验室计算平台使用 Slurm 管理作业资源。用户通过登录节点准备代码和提交作业，Slurm 将任务调度到可用计算资源上。

## 1.组成

- **登录节点**：编辑代码、准备环境、提交作业和查看日志。
- **计算节点**：执行 CPU 或 GPU 任务。
- **Slurm**：管理资源申请、队列和作业状态。
- **Lmod**：按需切换软件版本。
- **共享存储**：为用户或项目提供数据与结果存储。
- **Apptainer**：提供可复现的软件运行环境。

## 2.查看集群状态

```bash
sinfo # 查看集群节点概况
sinfo -N -o "%N %c %m %t %G" # 自定义查看每个节点的详情
squeue -u "$USER" # 查看自己的作业
```

## 4.查看硬件信息

查看 CPU 线程数：

```bash
lscpu
```

查看内存：

```bash
free -h
```

查看 GPU 型号与显存：

```bash
nvidia-smi
```

查看硬盘容量与使用情况：

```bash
lsblk
df -h
```

## 5.资源使用原则

- 只申请任务需要的 CPU、内存、GPU 和运行时长。
- 通过作业脚本明确声明资源，避免依赖登录 shell 的隐式状态。
- 不要在没有授权的情况下占用其他用户的进程、GPU 或数据。
- 如果节点处于 `drain`、`down` 或 `invalid` 等状态，请联系管理员，不要自行修改 Slurm 配置。
