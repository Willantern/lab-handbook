# 快速开始

## 推荐流程

1. 确认自己已获得服务器账号、SSH 登录方式和资源使用规则。
2. 登录后查看可用分区、节点和软件模块。
3. 将代码放在个人目录或项目目录，将数据放在获准使用的数据目录。
4. 编写 Slurm 脚本申请所需资源。
5. 通过 `sbatch` 提交任务，并使用 `squeue`、日志文件和 `sacct` 检查结果。

## 首次登录后检查

```bash
whoami
hostname
pwd
module avail
sinfo
```

若命令不可用或结果与手册不一致，请记录完整报错和执行命令，再联系管理员。

## 目录约定（示例）

| 路径 | 用途 |
|---|---|
| `$HOME` | 个人代码、配置和小型文件 |
| `/data/datasets` | 管理员维护的共享数据集（示例路径） |
| `/scratch/$USER` | 临时计算数据（仅在管理员已配置时使用） |
| `/opt/apps` | 公共软件安装目录，通常只读 |
| `/opt/modulefiles` | Lmod 模块文件目录，通常只读 |

这些路径只是常见布局示例，实际路径以本实验室配置为准。
